kubernetes kman
===============

Kubernetes management tools.

Install
-------
Install:

    ./kman.sh -inst -x
    -- or --
    ./kman.sh -anpb -x
    -- or --
    cp -fv kman.sh /usr/local/bin
    cp -fv zlocal-kman.sh /etc/profile.d

    mkdir -pv /usr/local/etc/kman.d
    mkdir -pv /usr/local/bin/alias-kman

Verify:

    km -ver

Help:

    km -h
